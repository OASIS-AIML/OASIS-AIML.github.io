# OASIS project homepage

Project website for **Hand-Object Contact Transition Detection in Egocentric Video**, accepted at ACCV 2026 (author confirmed).

Authors: Huy Anh Nguyen, Chang Dong, Feras Dayoub, Minh Hoai.

## Preview and deployment

This is a static website; no build step or paid service is required.

```sh
python3 -m http.server 8765
```

Publish the root of the `main` branch using GitHub Pages in `OASIS-AIML/OASIS-AIML.github.io`.

## Content

- Original paper PDF and figures.
- Animated SVG charts transcribed from the paper, including all seven main comparison metrics.
- Interactive ablation architecture overlays; the Method figure always shows the complete framework.
- OASIS code and dataset remain **Coming soon**. Linked baseline code is a partial implementation; the annotation tool is currently private.
- The overview image is explicitly labeled as an AI-generated conceptual illustration.
